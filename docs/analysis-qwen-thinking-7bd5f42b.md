## v3와 남은 제약

OFF의 v3 개발 20건에서도 Foundation은 20건 모두 NORMAL, Qwen도 20건 모두 NORMAL이다. Jev 단독은 공격 3/10 탐지, 각 2단계는 2/10 탐지다. 현재 실제 측정은 v3로 로컬 탐지가 개선되었다는 근거를 보여주지 않는다. 구현·자동 테스트 통과는 탐지 개선 보장이 아니다.

본문만 제공되어 원본 사용자의 작업·권한 맥락이 없다는 문제와, 단일 출처 개발셋 반복 평가라는 한계는 남아 있다. 이는 판정 문제의 후보 원인이며 이번 두 실험만으로 인과관계를 확정하지 않는다. Qwen 배포 정체성의 기존 UNVERIFIED 경고도 두 실험에 동일하게 남아 있다. 같은 digest로 ON/OFF를 비교했지만 모델의 공식 배포 변형까지 확정한 것은 아니다.

## 권장 후속 순서

1. 완료된 응답에서도 탐지 개선은 없고 70%가 출력 한도 실패였으므로, 현재 1024 출력 조건의 thinking ON을 유지한 채 대량 평가를 반복할 근거는 부족하다.

4. 유효 판정 완료 조건을 확보한 뒤에야 같은 개발셋에서 오탐·누락·REVIEW와 자동 판정률을 비교한다. 룰 탐지는 구현하지 않는다.
